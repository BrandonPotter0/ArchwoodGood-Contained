# Changelog

## [Unreleased]

### Added
- Added the vanilla Wither Rose as the Conjure Island: Archwood Forest offering for the Fading Archwood biome. The Wither Rose and Archfruit pod offerings are mutually exclusive.

## [1.2.11] - 2026-11-20

### Added
- Dawnberry and Lightchee Archfruit pods select the Dawning and Blinding Archwood biomes when used to augment Ars Elemental's Conjure Island: Archwood Forest ritual, using the existing Archwood variant registry.
- Documented support for both Conjure Island and Tablet of Forestation ritual integrations.

### Changed
- Updated the Ars Elemental dependency to 0.7.11.3 (CurseForge file 9716535).
- Updated the mod version to 1.2.11.

## [1.2.9] - 2026-11-17

### Added
- Added Ars Elemental Tablet of Forestation ritual compatibility for Archwood Good's Dawning (Orange), Blinding (White), and Fading Archwood variants.
- Added support for mixed forest rituals to generate the five original Ars Elemental Archwood variants alongside Dawning and Blinding Archwood.
- Added Dawberry and Lightchee pod generation to the corresponding custom Archwood ritual variants and mixed forests.

### Fixed
- Added Fading Archwood sapling drops from leaves, using the same standard drop chances and Fortune behaviour as the other Archwood Good leaf types.
- Corrected Fading Archwood loot-table generation so its Ars Nouveau-namespaced leaves receive the appropriate sapling drop table.

### Changed
- Made Ars Elemental a required dependency.
- Updated the mod version to 1.2.9.
- Changed the built JAR filename format to `Archwood_Good - 1.2.9.jar`.
